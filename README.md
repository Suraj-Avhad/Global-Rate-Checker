# Global-Rate-Checker

 Built a web-based currency converter to check real-time exchange rates across multiple countries.
 Integrated third-party APIs to fetch live conversion rates and displayed results with dynamic country images.


## Features

🌐 Real-time currency conversion

🔄 Live exchange rates using third-party APIs

🖼️ Dynamic country images/flags

⚡ Fast, responsive UI

📱 Mobile-friendly layout

## Tech Stack

*HTML, CSS, JavaScript*

*Third-party Exchange Rate API (e.g., ExchangeRate-API, Frankfurter API, etc.)*

*Fetch API for real-time data*

## How It Works


User selects From Currency and To Currency

App requests live rates from API

Calculates conversion value dynamically

Updates UI with corresponding country flag and converted value
